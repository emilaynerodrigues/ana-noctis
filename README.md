# 🌙 Ana Noctis

### *A Noite de Ana*

> **Noctis**, em latim, significa **“da noite”**.

**Ana Noctis** é um projeto inspirado no universo de **Trono de Vidro** e na **Ana**, criado para transformar lembranças, sentimentos e pequenos detalhes em uma experiência interativa e pessoal.

Cada elemento do site foi pensado e desenhado à mão: **cada traço, cada estrela, cada montanha, cada flor e cada detalhe da espada**.

Não é apenas um site, é a representação visual de um sentimento que existe no meu peito e pertence a *ela*.

É uma pequena noite criada para guardar lembranças de alguém especial.

Link de acesso: https://emilaynerodrigues.github.io/ana-noctis/

---

## 🌙 A experiência

O site começa em silêncio e, aos poucos, o cenário é construído.

Os elementos aparecem um por um, como se alguém estivesse desenhando aquela noite.

Depois, o dia dá lugar à noite.

As estrelas ganham luz, as constelações aparecem, a lua se ilumina e a Goldryn passa a brilhar.

No final, as cartas podem ser abertas.

Cada acesso pode revelar uma carta diferente.

E algumas coisas foram deixadas escondidas de propósito.

Tudo aqui é sobre *ela*.

---

## ⚔️ Trono de Vidro

**Ana Noctis** não é uma adaptação de *Trono de Vidro*.

É uma homenagem pessoal àquilo que a saga representa para mim.

A linguagem visual e alguns símbolos foram inspirados na atmosfera da obra, especialmente em elementos como:

**Aelin • Rowan • Celaena • Dorian • Yrene • Elide • Lysandra • Lorcan • Chaol**

Tudo aqui faz referência a algo importante e especial sobre *ela*.

---

## 💌 As cartas

As cartas são uma das partes centrais do projeto.

Cada uma possui uma pequena história, uma referência ou uma lembrança.

Algumas falam diretamente.
Algumas falam através dos personagens.
Algumas escondem pequenos detalhes.

E uma delas guarda um girassol. 🌻

---

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando:

* **HTML5**
* **CSS3**
* **JavaScript**
* **SVG**
* **EmailJS**

As animações foram construídas principalmente com **JavaScript e CSS**, manipulando os elementos SVG diretamente no navegador.
